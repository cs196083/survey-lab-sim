# 립밤 설문 실습실

중학교 정보 Ⅱ. 데이터 5~6/12차시 실습용 시뮬레이션입니다. 더러운 설문 데이터를 규칙에 따라 정제하고, 좋은 설문 문항을 설계합니다.

**바로 가기: https://cs196083.github.io/survey-lab-sim/**

## 구성

- 5차시 데이터 정제: 예측, 오류 6종 찾기, 규칙 정하기, 전후 비교, Labels/Values 표, 선언문
- 6차시 설문 설계: 나쁜 문항 진단, 점검표, v2 고치기, 윤리 안내, 파일럿, 성찰

6차시 파일럿 결과는 수업용 가상 예시입니다. 학생의 답은 서버로 전송되거나 저장되지 않습니다.
